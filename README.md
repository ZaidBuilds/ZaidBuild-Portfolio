# ⚡ Zaid Minimal Portfolio
Performance-optimized minimal developer portfolio website built for Mohd Zaid.

Status: 95% complete — PACKAGE

## 🚀 Features
*   **Ultra-lightweight Layout**: Designed with minimal JS scripts to maximize page speed.
*   **Responsive Styling**: Grid layouts looking sharp on mobile and desktop viewports.
*   **CSS Animations**: High-converting scrolling and header animations.

## 🛠️ Tech Stack
*   **Frontend**: HTML5, CSS3, React
*   **Deployment**: Netlify SPA Redirect Routing
