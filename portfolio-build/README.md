## ⚡ INITIALIZATION

To boot the neural interface on your local node:

```bash
# Clone the repository (if not already local)
git clone https://github.com/ZaidBuilds/ZaidBuild-Portfolio.git

# Navigate to the core directory
cd portfolio-build

# Install dependencies
npm install

# Initialize development sequence
npm run dev
```
